# Source code (for binaries)

This directory contains the source code for the different binary programs.

## Directory structure

| Relative directory | Description                        |
| ------------------ | ---------------------------------- |
| `./maker/`         | Custom build script system         |
| `./c_*/`           | Classical compiler                 |
| `./ch_*/`          | Classical hardware compiler        |
| `./ct_*/`          | Classical transpiler               |
| `./b_*/`           | Biological [hardware] compiler     |
| `./q_*/`           | Quantum compiler                   |
| `./qh_*/`          | Quantum hardware compiler          |
| `./*share/`        | Shared resources for compiler type |
